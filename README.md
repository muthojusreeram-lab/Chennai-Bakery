🥐 Chennai Bakery E-Commerce Platform (https://ai.studio/apps/6ed034d9-cad7-4313-b444-0ae45b61d977)
Welcome to the repository for Chennai Bakery, a vibrant, full-featured e-commerce web application designed for a local artisan bakery in Chennai. The platform specializes in authentic regional flavors, daily fresh bakes, and healthy/diabetic-friendly treats, providing a seamless shopping experience for customers and a robust management dashboard for administrators.

🌟 Key Features
🛒 Customer-Facing Features
Product Discovery & Smart Search: Real-time product search with autocomplete, image previews, and instant filtering.

Dynamic Catalog & Filtering: Dedicated categories (Cakes, Breads, 100% Eggless, etc.) with quick-toggle dietary filters (Low-Calorie, Diabetic-Friendly, Vegan, Gluten-Free).

Detailed Product Customization: Dynamic pricing based on size/weight selection, live stock indicators, and full transparency on ingredients, nutritional values, and allergens.

Localized Delivery Validation: Integrated Chennai PIN code verifier (covering 600001–600130) with instant locality feedback and delivery turnaround times.

Smart Cart & Scheduling: Slide-over cart drawer with free-delivery thresholds, date/time slot selection (Morning, Afternoon, Evening Tea, Dinner).

Seamless Checkout & Order Tracking: Simulated payment gateway (UPI, Cards), printable invoices, and a live 4-stage order status tracker (Received → Baking → Out for Delivery → Delivered).

Customer Engagement:

Loyalty Program: Earn points on every purchase (1 point per ₹10 spent) with tiered progression (Bronze, Silver, Gold, Mylapore VIP).

Wishlist: Save favorite items for later.

Reviews: Interactive 5-star rating and commenting system.

🔐 Admin Dashboard
Secure Access: Gated entry for authorized administrators to manage the platform.

Product Management (CRUD): Add, edit, and delete products, manage bilingual titles (English/Tamil), dietary tags, and upload product images.

Order Management: View comprehensive order records, track itemized purchases, and update live order statuses for customers.

Performance Metrics: Real-time summary cards displaying daily revenue and total order counts.

🛠️ Tech Stack (Inferred)
Frontend: React, TypeScript (.tsx), HTML5, CSS3

Styling: Modern CSS framework (Tailwind CSS) with a custom "Vibrant Palette" (Warm amber, terracotta, teal).

Backend/Database: Firebase (for persistent data storage of products, user sessions, and orders).
